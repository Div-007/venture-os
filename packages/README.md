# Packages

| Package | What it holds |
|---|---|
| [`contracts`](contracts) | Shared zod schemas and the API and event contracts used by the web app, API, worker and MCP tools |
| [`core`](core) | Framework-independent domain logic: permissions, reminders, tokens, calendar and commands |

Both are built first by `npm run build`. Overview: [../README.md](../README.md).
